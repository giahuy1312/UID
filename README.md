# OCEAN - Giao diện theo bộ ảnh mẫu

React + Vite, chỉ frontend. 18 trang/màn hình gồm trang chủ, danh mục cá, phụ kiện, thức ăn, tìm kiếm, chi tiết, giỏ hàng, đặt hàng, cẩm nang, bài viết, giới thiệu, liên hệ, đăng nhập, đăng ký, tài khoản, lịch sử đơn hàng, chi tiết đơn hàng.

## Chạy trên Windows

1. Cài Node.js 20 trở lên.
2. Giải nén, mở thư mục trong VS Code.
3. Chạy `npm install`.
4. Chạy `npm run dev`.
5. Mở địa chỉ Vite in trong terminal (thường là http://localhost:5173).

Dữ liệu, tài khoản, giỏ hàng, đặt hàng là minh họa. Giỏ hàng lưu localStorage. Không có backend hoặc thanh toán thật. Ảnh sản phẩm được cắt từ ảnh tham khảo do người dùng cung cấp nên một số ảnh có độ phân giải hạn chế.
